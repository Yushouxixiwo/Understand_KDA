01 / DECAY

遗忘，是一只可学习的时钟。

这里的“物理意义”是离散动力系统的解释：每个 key 通道像一个独立的泄漏记忆单元。

调整通道保留率 α

α 越接近 1，旧信息保留越久。图中只观察衰减，暂时关闭新信息写入。

旧记忆的剩余比例m(t) = αt m(0)
归一化初始记忆 m(0) = 1 横轴：token 步数 · 纵轴：剩余比例
α

保留率，不是写入强度

α 乘在状态的行上。S ∈ ℝK×V 时，第 j 个 α 同时衰减第 j 行的所有 value 分量。

S̄j,: = αj · Sj,:
τ

从门控读出时间尺度

固定 α 时，τ 是降到初值 1/e 所需的步数；半衰期是降到 1/2 的步数。实际模型的 α 随 token 改变。

τ = −1 / ln α   ·   t½ = ln(½) / ln α
g

内核通常接收 log gate

g = ln α ≤ 0。跨多步的乘积变成加法：累计 log gate 后取指数，便于分块计算。

∏ αℓ,j = exp(Σ gℓ,j)
进一步理解：safe gate 为什么仍需要数值稳定的计算？ ＋

一种有下界的门控写法是 g = −c · sigmoid(exp(A_log) · (x + b))，因此 g ∈ (−c, 0)，α ∈ (exp(−c), 1)。它限制单步遗忘的强度，但累计 G 仍可能很负。

计算 exp(Gᵢ − Gⱼ) 时，不能随意拆成 exp(Gᵢ) · exp(−Gⱼ)：后者可能产生溢出或下溢的中间值。稳定分块、精度与门控范围必须一起设计。这里的滑块直接控制 α，不模拟门控投影网络。

示例固定 k = [0.8, 0.6, 0]，‖k‖₂ = 1；v = [0.3, −0.5, 0.9]；q = [0.6, 0, 0.8]。q 已视为有效读出向量，未另乘缩放。β = 1 时，更新后的 Sᵀk = v；β = 0 时，只遗忘、不纠错。

为什么叫 DELTA RULE

把状态 S 看成从 key 到 value 的在线线性映射，对当前样本的平方预测误差做一步梯度下降。

ℒ(S) = ½ ‖S⊤k − v‖²   →   S ← S + β k(v − S⊤k)⊤

KDA 先把 S 换成衰减后的 S̄，再执行这一步。遗忘门 α 与学习率 β 各自承担不同职责；矩阵乘法的先后顺序不能交换。

03 / PERFORMANCE

同一个递推，两条优化路线。

decode 关注状态的读写；prefill 关注时间依赖和矩阵计算。先确定瓶颈，再选择实现。

优先减少全局内存往返

让状态留下来，
让中间结果不落地。

每个 head 的 FP32 状态大小为 K × V × 4 字节。多个独立 kernel 若反复读写状态，会让轻量计算付出额外搬运成本。

状态 / 临时结果尽量驻留局部存储写 S

融合以局部存储容量、布局和编译结果允许为前提。单次 decode 仍通常需要从状态缓存读入，再写回；跨调用永久驻留不能直接假定。

01

batch × head，并行不足再切 V

不同 value 列可独立更新。沿 V 切状态能增加并行度；沿 K 切则需要合并预测和读出的归约结果。

02

小矩阵向量计算，比较 Vector 与 Cube

单 token 的两次归约和外积很小。Cube 的转换、搬运与同步成本可能超过算力收益，需按 shape 实测。

03

FP32 状态，检查连续递推

除输出误差外，还要比较最终状态与长时间 decode 漂移。复用 buffer、减少启动和分配，再看端到端 TPOT。

把 token 依赖压进 chunk

块内做矩阵，
块间传状态。

对一个 chunk，先并行计算门控交互与三角变换，再用进入状态 S₀ 得到纠错量 R。标准 chunk 执行的跨块状态链仍然存在。

实现时用专用三角求解或分块变换，不必构造通用逆矩阵。

展开符号：L、P 和累计衰减怎么定义？ ＋

Gᵢ = Σℓ≤i gℓ，B = Diag(β)。所有下标都在当前 chunk 内。

Lᵢⱼ = βᵢ kᵢᵀ Diag(exp(Gᵢ − Gⱼ)) kⱼ，j < i；其他元素为 0。

Pᵢⱼ = qᵢᵀ Diag(exp(Gᵢ − Gⱼ)) kⱼ，j ≤ i；其他元素为 0。

K₊、Q₊ 的第 i 行分别为 (exp(Gᵢ) ⊙ kᵢ)ᵀ、(exp(Gᵢ) ⊙ qᵢ)ᵀ。K_end 的第 j 行为 (exp(G_C − Gⱼ) ⊙ kⱼ)ᵀ；D_C = Diag(exp(G_C))。

01

分离独立预计算与状态链

块内门控、交互、三角变换不依赖 S₀，尽量跨 chunk 并行；不要把所有工作放进串行循环。

02

chunk 大小是取舍，不是越大越好

较大 C 缩短状态链，但增加块内 C² 交互、临时存储和三角处理成本。这里的计数是工作量示意，不预测性能。

03

分块三角算法与 CV 流水

小对角块求解结合较大矩阵乘；减少重复拷入拷出，让不同 chunk 的 Vector 预处理与 Cube 计算重叠。
